# Star Chart

A responsive web application for tracking good and bad behavior with stars. Built with React and designed to run entirely in the browser with local storage persistence.

## Features

- ⭐ Track good and bad behavior with stars
- 📅 Daily view for adding stars to any date
- 📊 Weekly report showing totals and daily breakdown
- 💾 Automatic saving to browser localStorage
- 📱 Responsive design for mobile and desktop
- 🚀 Deployed to GitHub Pages

## Usage

### Daily View
- Navigate between days using the Previous/Next buttons
- Click "Good Star" to add a good behavior star
- Click "Bad Star" to add a bad behavior star
- View today's total stars at the bottom

### Weekly Report
- Navigate between weeks using the Previous/Next buttons
- See the week's total good and bad stars
- View a daily breakdown for each day of the week

## Development

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Deploy to GitHub Pages
```bash
npm run deploy
```

## Technical Details

- Built with React 18
- Uses Vite for fast development and building
- Data persisted in browser localStorage
- No backend required - runs entirely client-side
- Deployed to GitHub Pages
